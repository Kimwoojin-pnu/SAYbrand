API 레퍼런스

인증

모든 /api/* 엔드포인트는 Authorization: Bearer <JWT> 헤더 또는 세션 쿠키 필요.

대시보드 /api/dashboard

엔드포인트

메서드

설명

/api/dashboard/threats

GET

위협 목록 (필터·정렬·페이지)

/api/dashboard/threats/{id}

GET

위협 상세

/api/dashboard/threats/{id}

PATCH

상태 변경 (active/dismissed/resolved)

/api/dashboard/scan

POST

스캔 실행 (Vercel→Celery / 로컬→직접)

/api/dashboard/scan-local

POST

로컬 전용 직접 스캔

/api/dashboard/stats

GET

통계 (severity별·platform별)

/api/dashboard/version

GET

서비스 버전 (v0.3.1)
