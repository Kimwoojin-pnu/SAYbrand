제품 개요
=========

제품 정의
---------

SAYbrand는 공개 SNS 데이터를 AI로 실시간 분석해 브랜드를 위협하는 모든 요소를 사전 탐지·대응하는 **B2B 보안 SaaS**입니다.

타겟 고객
~~~~~~~~~

.. list-table::
   :widths: 25 40 35
   :header-rows: 1

   * - 세그먼트
     - 설명
     - 주요 니즈
   * - **B2C 브랜드**
     - 뷰티·패션·식품 등 소비재 브랜드
     - 사칭 계정, 바이럴 루머 대응
   * - **중견기업**
     - 브랜드 모니터링 체계 없는 기업
     - 첫 모니터링 솔루션
   * - **개인 인플루언서**
     - 팔로워 1만+ 크리에이터
     - 사칭 계정, 악의적 루머

3대 핵심 모듈
--------------

모듈 A — 브랜드 사칭 탐지
~~~~~~~~~~~~~~~~~~~~~~~~~~

- 공식 로고·CI 이미지 유사도 비교 (pHash 해밍 거리)
- 교묘하게 변형된 로고, 워터마크 제거 이미지 탐지
- CEO·모델 프로필 사진 도용 계정 탐지

모듈 B — 가짜뉴스·루머 분석
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- 브랜드 관련 부정 콘텐츠 실시간 수집
- **조직적 봇 공격 vs 실제 소비자 불만** 자동 구분
- 봇 확률(0.0–1.0) 자동 산출
- 여론 확산 속도 및 위험 임계값 모니터링

모듈 C — 임직원 평판 모니터링
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- 공개 SNS 내 임직원 언급 모니터링
- 명예훼손·내부 정보 유출 징후 탐지
- 임직원 우선순위 차등 (CEO=1.5x / 임원=1.2x / 일반=1.0x)
