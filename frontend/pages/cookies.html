쿠키 정책

시행일: 2026년 1월 1일  |  최종 수정: 2026년 6월 1일

쿠키란 무엇인가요?

쿠키(Cookie)란 웹사이트를 방문할 때 브라우저에 저장되는 소량의 텍스트 파일입니다. 쿠키를 통해 서비스는 이용자의 설정을 기억하고, 로그인 상태를 유지하며, 서비스 이용 통계를 수집합니다.

SAYbrand는 서비스 운영에 필수적인 쿠키만 사용하며, 광고 목적의 제3자 추적 쿠키는 사용하지 않습니다.

사용하는 쿠키 목록

쿠키명유형목적보존 기간
session 필수 로그인 세션 유지. 이 쿠키 없이는 서비스를 이용할 수 없습니다. 브라우저 종료 시 삭제
ld-theme 기능 다크모드/라이트모드 설정 기억 (localStorage에 저장) 영구 (명시적 변경 전까지)
wl_config 기능 화이트 라벨 색상 설정 캐시 (localStorage에 저장, 5분 TTL) 5분 후 자동 만료
_vercel_analytics 분석 Vercel 플랫폼의 익명 방문자 통계 (개인 식별 불가) 24시간

쿠키 유형 설명

  • 필수 서비스 운영에 반드시 필요한 쿠키입니다. 비활성화 시 서비스 이용이 불가합니다.
  • 기능 편의 기능(다크모드, 설정 저장 등)을 위한 쿠키입니다. 비활성화 시 설정이 매번 초기화됩니다.
  • 분석 서비스 이용 현황 파악을 위한 익명 통계 쿠키입니다. 개인정보를 포함하지 않습니다.

사용하지 않는 쿠키

SAYbrand는 다음 쿠키를 사용하지 않습니다.

  • 광고·마케팅 목적의 제3자 추적 쿠키 (Google Ads, Meta Pixel 등)
  • 교차 사이트 행동 추적 쿠키
  • 프로파일링 목적의 쿠키

쿠키 관리 방법

브라우저 설정을 통해 쿠키를 관리할 수 있습니다. 필수 쿠키를 차단하면 로그인 등 핵심 기능이 작동하지 않을 수 있습니다.

  • Chrome: 설정 → 개인정보 보호 및 보안 → 쿠키 및 기타 사이트 데이터
  • Firefox: 설정 → 개인정보 보호 → 쿠키 및 사이트 데이터
  • Safari: 설정 → 개인정보 보호 → 크로스 사이트 추적 방지
  • Edge: 설정 → 쿠키 및 사이트 권한 → 쿠키 및 저장된 데이터 관리
