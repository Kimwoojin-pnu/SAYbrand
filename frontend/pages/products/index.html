오탐(false positive)은 어떻게 줄이나요?

이미지 유사도와 계정 행동 패턴을 함께 분석해 단순히 로고가 비슷하다는 이유만으로 위협으로 분류하지 않습니다. 위협 점수가 낮은 항목은 별도로 분류되어 알림 피로도를 줄입니다.

어떤 플랫폼을 지원하나요?

Instagram, X(Twitter), TikTok, YouTube, Naver를 지원하며, 플랜에 따라 모니터링 가능한 플랫폼 수가 다릅니다. 자세한 내용은 요금 페이지를 참고해 주세요.

신고 가이드는 실제로 신고까지 자동으로 처리하나요?

신고 가이드는 플랫폼별 신고 절차와 필요한 근거 자료를 정리해 제공합니다. 최종 신고 제출은 계정 소유자 확인 등의 이유로 사용자가 직접 진행해야 합니다.

워터마크를 지운 이미지도 탐지할 수 있나요?

네. pHash 기반 비교 외에 CLIP 임베딩을 함께 사용해 워터마크 제거나 일부 변형이 있는 이미지도 원본 로고와의 유사도를 비교해 탐지합니다.

오탐 시 직접 검토할 수 있나요?

네. 위협 목록에서 각 항목의 판단 근거(봇 확률, 유사 게시물 묶음 등)를 확인하고 상태를 직접 변경할 수 있습니다.

FAQ

자주 묻는 질문

L1/L2/L3는 각각 어떤 AI를 사용하나요?

L1은 키워드·정규식 기반 규칙 필터(AI 미사용), L2는 Gemini Flash와 Vision API를 사용한 텍스트·이미지 분석, L3는 Claude Haiku 4.5를 사용한 심층 분석입니다.

모든 콘텐츠가 Claude Haiku로 분석되나요?

아니요. L1·L2를 통과한 고위협 콘텐츠(약 5%)만 L3로 전달되어 Claude Haiku 4.5가 분석합니다. 모든 콘텐츠를 L3로 보내면 비용이 크게 늘어나기 때문에, 단계적으로 좁혀가며 처리합니다.

API로 직접 연동할 수 있나요?

현재 SAYbrand는 대시보드를 통해 분석 결과를 제공합니다. 별도의 외부 개발자용 REST API는 아직 제공되지 않으며, 필요한 경우 영업팀에 문의해 주세요.

분석 결과는 얼마나 빠르게 반영되나요?

L1 필터는 즉시 처리되며, L2·L3 분석은 수집 주기에 따라 백그라운드에서 처리되어 대시보드의 위협 목록에 순차적으로 반영됩니다.
